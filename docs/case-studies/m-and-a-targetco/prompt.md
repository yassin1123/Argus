# Prompt — ExampleCo M&A diligence (stub)

## Question

> Evaluate **ExampleCo** as an acquisition target given recent revenue compression and pending litigation.

## Mode

`due_diligence` — requires **financial**, **legal**, and **operational** branches with a minimum of 3 evidence objects per branch.

## Anticipated intake questions

- What is the strategic rationale for the acquisition (capability, market, talent, defensive)?
- What is the deal-breaker red-line (e.g., unresolved litigation, customer concentration above N%)?
- What internal documents will you provide (10-K, customer list, key contracts, litigation summary)?

## Why this is a stub

The full deliverable requires running the live pipeline against uploaded inputs. This stub seeds the homepage so the workspace looks lived-in and shows that Argus supports multiple engagement types beyond market entry.
