# Prompt — Value-based vs seat-based pricing (stub)

## Question

> Should we shift from **seat-based** to **value-based** pricing for our enterprise tier?

## Mode

`growth_strategy` — requires **market** and **capabilities** branches with a minimum of 2 evidence objects per branch.

## Anticipated intake questions

- What is the current ACV mix and seat distribution by tier?
- What "value metric" candidates have been considered (API calls, monthly active users, transactions processed, GMV)?
- What is the target migration window for existing customers?

## Why this is a stub

The full deliverable requires running the live pipeline against uploaded usage data and ACV cohorts. This stub seeds the homepage so the workspace looks lived-in and shows that Argus supports `growth_strategy` engagements alongside market-entry and due-diligence.
